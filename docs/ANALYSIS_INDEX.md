# Analysis index

Filenames describe analyses independently of manuscript numbering. Formatted regression tables
contain odds ratios, 95% confidence intervals and significance stars. Corresponding
`_long.csv` files contain numeric estimates and exact p-values. The
[complete output inventory](../outputs/INDEX.md) lists model summaries, sample accounting,
covariance components and annual ACS replicate coefficients.
